How it works

1Voice noteThe patient answers six short questions by holding a WhatsApp-style mic button, or types. Nothing talks back.
2Speech to textLocal Whisper turns each voice note into Spanish text, on the laptop, even offline.
3GeminiTurns everyday Spanish ("apretón en el pecho", "patatús") into a fixed clinical chart, keeping the patient's own words.
4JevReads only the structured chart and returns the probability of each ESI level, with a confidence score.
5Safety ruleUnder-triage costs 10x over-triage, so ambiguous cases are flagged more urgent. The math is printed on the sheet.
6Nurse confirmsThe nurse reads the Spanish summary back, fixes any line, and assigns the official ESI. Then the PDF is final.

What it never does

  • It never diagnoses and never shows a triage level to the patient.
  • It never assigns the official ESI. The nurse does; the system only suggests a review tier.
  • It never presents stored examples as model output. Every screen, sheet, and file says which parts were live.
  • It never uses real patient data in this demo. All cases are synthetic.
